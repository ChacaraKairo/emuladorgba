# Emulador GBA focado em Pokémon

Projeto multiplataforma para executar jogos de Game Boy Advance fornecidos legalmente pelo usuário, com foco em compatibilidade com jogos Pokémon, organização de biblioteca e compartilhamento seguro de saves entre celular e computador.

## Objetivos iniciais

- núcleo de emulação baseado no mGBA;
- Android, Linux e Windows;
- saves de cartucho portáveis entre plataformas;
- backups automáticos e detecção de conflitos;
- suporte correto a RTC;
- controles por toque, teclado e gamepad;
- nenhuma ROM ou BIOS distribuída pelo projeto.

## Estado

Projeto em fase inicial de arquitetura e prova de conceito.

## Aviso legal

Este projeto não fornece jogos, ROMs, BIOS ou conteúdo protegido. O usuário é responsável por utilizar arquivos obtidos legalmente.
