# Registros de decisões arquiteturais

ADRs registram decisões difíceis de reverter, contexto, alternativas e consequências.

## Formato

```text
# ADR-NNN — Título
Status: proposta | aceita | substituída | rejeitada
Data: AAAA-MM-DD

## Contexto
## Decisão
## Alternativas consideradas
## Consequências
## Critérios de revisão
```

## Regra

Mudanças em núcleo, formato de save, framework de interface, sincronização, banco de dados ou licença precisam de ADR antes da implementação.
